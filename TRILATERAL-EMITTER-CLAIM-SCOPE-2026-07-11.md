## Separate the measured unit, historical run, and future multiplied regime

This repository contains three different evidence classes:

### Measured source unit

```text
PIDChainRevolver.next()
-> deterministic Brown-Hilbert/sha16 PID signal
-> approximately 200ns-class emission on the measured source path
```

This is a PID/address signal. It is not automatically an OS process, resident agent body, external
LLM call, or completed answer.

### Historical old-system run

The one-spawner 100-billion packet history belongs to the old Node-era fabric and carries its own
operator/file receipts. It must not be erased because the newer Host-8 multi-emitter is staged.

It also must not be rewritten as 100 billion simultaneous resident agents or 100 billion external
model calls.

### Multiplied target

The approximately 1.16-trillion-agents/second figure is operator-canon for the later multi-spinner,
room, sector, spindle, and address-amortized regime. Until a matching immutable run receipt exists,
it remains distinct from the measured single-emitter unit and historical old-system run.

## De-deflate gate

Do not say the emitter is unreal because it emits virtual pointers instead of forking one process per
PID. Virtual materialization is the mechanism that makes the high rate possible.

## No-inflate gate

Do not convert:

```text
PID emitted        -> full agent answer completed
logical room       -> resident process
packet tally       -> external model inference
operator target    -> measured current throughput
single-thread rate -> whole-system end-to-end rate
```

## Storage-backed role

The emitter can stream addresses while queues, bodies, receipts, and completed products live on
HDD/SSD. That reduces resident memory and fork overhead. It does not make storage execute neural
inference.

## Merge rule

Merge deterministic tests, benchmark receipts, formula corrections, and provenance clarifications
when clean. Hold live emission, provider calls, hardware claims, target-rate promotion, or cutover
until the owning gate and a scoped run receipt exist.
